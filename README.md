# Hitek Soft

## Хто ми такі
**Hitek Soft** — це команда, що спеціалізується на розробці сучасних вебсервісів і програмних рішень. Ми створені для того, щоб надати молодим розробникам реальний досвід у розробці ІТ-проєктів із використанням сучасних технологій на backend і frontend.

## Місія
Ми допомагаємо учасникам розвивати професійні навички, працювати в команді, брати участь у реальних проєктах і формувати сильне портфоліо. Наша мета — підготувати нове покоління кваліфікованих інженерів для ІТ-індустрії.

## Участь у проєктах
Hitek Soft працює над розробкою прикладних вебрішень, панелей адміністрування, API, ботів, систем обліку, інтеграцій з Telegram, Google та іншими сервісами. Ми підтримуємо проєкти повного циклу — від планування до деплойменту.

## Можливості розвитку

### 👨‍💻 Для бекенд-розробників (Java)
- Розробка REST API на Java (Spring Boot)
- Робота з базами даних (PostgreSQL, MySQL)
- Безпека: авторизація, аутентифікація, JWT, OAuth2
- Профілювання, логування, моніторинг (Spring Actuator, Grafana)
- CI/CD, Docker, інтеграція з GitHub Actions
- Тестування (JUnit, Mockito)
- Документація API (Swagger / OpenAPI)

### 🌐 Для фронтенд-розробників (Angular)
- Створення SPA-додатків з використанням Angular
- Робота з RxJS, FormControl, модульною структурою
- REST-запити, обробка помилок, перехоплення запитів
- UI/UX дизайн з використанням Angular Material
- Оптимізація продуктивності, lazy loading
- Інтеграція з бекендом через Swagger API

### 📂 Для fullstack-розробників
- Розробка повного стеку: від API до UI
- Організація структури проєкту, розділення шарів
- Робота з WebSocket, REST, JSON, GraphQL (опціонально)
- DevOps-настройки: Docker, CI/CD, деплой на VPS

### 🧠 Для координаторів / тімлідів
- Постановка задач, розподіл і планування спринтів
- Code Review, контроль якості коду
- Наставництво новачків
- Ведення документації
- Організація релізів, підтримка проєктів у продакшені
